# BlackPyre 1.0 App Store Screenshots

This package contains the English (U.S.) iPhone master screenshot set for BlackPyre 1.0.

- Device class: 6.9-inch iPhone display
- Pixel size: 1320 × 2868 portrait
- Format: JPEG, no alpha channel
- Source: native Simulator build of the current iOS candidate
- Data: fictional screenshot-only profile created by
  `tools/prepare-app-store-screenshots.js`
- RAW personal data: never used

## Upload order

1. `01-home.jpg` — journey, water history, and optional Apple Health summary
2. `02-food.jpg` — food search, barcode entry, and quick-log choices
3. `03-barcode-verification.jpg` — scanned serving and nutrition verification workflow
4. `04-train.jpg` — current program and exercise-entry controls
5. `05-rest-timer.jpg` — active floating rest timer during training
6. `06-weight.jpg` — dated weight entry and trend projection
7. `07-apple-health.jpg` — optional Health data controls and workout sharing
8. `08-data-recovery.jpg` — backup, external save, restore, and Native Vault recovery

Apple accepts one to ten screenshots. A highest-resolution 6.9-inch set can be used as
the master set when the interface is the same across supported iPhone sizes.

`MANIFEST.sha256` records the exact upload files.
