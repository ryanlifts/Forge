BLACKPYRE NATIVE v80 — PHASE 2 KEYLESS FOOD DATA
AUTHORITATIVE WEB-PARITY HANDOFF

PURPOSE
-------
Phase 2 removes BlackPyre's dependency on a shipped, shared, or user-entered
USDA API key while preserving practical food logging and all previously
validated nutrition-safety and workout-card behavior.

AUTHORITATIVE NATIVE BEHAVIOR
-----------------------------
1. No shipped or embedded USDA API credential is used.

2. USDA API-key controls, signup instructions, and settings language are
   removed from the user interface and FAQ.

3. Legacy cfg.usdaKey data is removed during migration and is excluded from
   normal BlackPyre backups.

4. Existing bundled/local generic food suggestions remain available without
   an internet connection or user account.

5. Packaged-food and barcode lookup uses the stable Open Food Facts v2 product
   endpoint.

6. Results obtained from Open Food Facts visibly identify:
   Source: Open Food Facts

7. Users are reminded to compare database information with the package
   nutrition label because the physical label is the controlling source for
   the product in hand.

8. A barcode that is not found opens manual nutrition-label entry after one
   lookup request.

9. A temporary lookup failure retries once and then opens manual
   nutrition-label entry rather than trapping the user in an error state.

10. Ordinary rapid repeated Add actions are blocked to prevent accidental
    double logging.

11. The explicit duplicate control intentionally creates another copy of an
    existing food entry.

12. Identical items contained in one reviewed AI-food batch are preserved
    because they may represent intentional separate servings.

PRESERVED CONTRACTS
-------------------
Phase 2 must not weaken or replace the completed Phase 1 nutrition-safety
system, including:

- Ages 13 through 100.
- Exact 2023 DRI youth energy equations for ages 13 through 17.
- Transactional validation and visible inline errors.
- The universal 1,200-calorie minimum.
- Safe calculator-input persistence.
- Teen activity-category guidance and complete teen controls.

Phase 2 also preserves the complete profile-aware workout-card system for all
203 active canonical exercises, including timed holds, steady cardio,
intervals, carries, conditioning rounds, repetition work, and strength work.

WEB PARITY REQUIREMENTS
-----------------------
A future web implementation should reproduce the user-visible and data-safety
behavior above. It must not copy native packaging details or access the native
repository as part of web development.
